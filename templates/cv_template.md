<!-- 
======================================================================================
GENERAL TEMPLATE GUIDELINES FOR AJSAA COMPATIBILITY
======================================================================================

FILE FORMAT:
- Save as .md (markdown) file
- UTF-8 encoding
- No special characters in filename (use: firstname_lastname_cv.md)

LENGTH:
- Target 1,500-2,500 words
- AJSAA's LLM has token limits—longer CVs get truncated
- Prioritize recent and relevant experience

KEYWORDS:
- Mirror language from your target job descriptions
- Use industry-standard terms (avoid proprietary jargon)
- Include both spelled-out terms and acronyms (e.g., "Machine Learning (ML)")

FORMATTING:
- Use standard markdown (no fancy extensions)
- Avoid tables (hard for LLMs to parse)
- Use consistent heading levels (## for main sections, ### for subsections)
- Use hyphens (-) for bullets, not asterisks (*)

METRICS:
- Quantify everything possible (%, $, time, scale)
- Use "before → after" format for improvements (e.g., "150 → 40 incidents")
- Include context for numbers (e.g., "serving 10M users" not just "10M")

WHAT TO AVOID:
- Photos or images (LLM can't parse them)
- Multiple columns (breaks parsing)
- Headers/footers with contact info (put in Location & Contact section)
- Buzzwords without substance ("synergy", "rockstar", "ninja")
- Personal pronouns ("I", "my", "we")—use active voice without pronouns

AJSAA PARSING PRIORITIES:
1. Technical Stack (matches against job requirements)
2. Target Roles (filters job search)
3. Recent Experience (2-3 most recent roles weighted heavily)
4. Key Strengths (used for scoring match quality)
5. Certifications (binary match: have it or don't)
6. Location & Remote (filters geographically)

For best results, keep this CV updated and re-run AJSAA weekly to catch new postings.
======================================================================================
